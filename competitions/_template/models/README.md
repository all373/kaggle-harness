# __SLUG__ で使うモデルファイル

このコンペだけで使う重み、前処理設定、辞書などを置きます。
モデルの Python コードは `src/models/` に置いてください。

実験中のチェックポイントは渡された `output_dir`（通常 `runs/` 内）に保存し、
利用するモデルを選んでからこのフォルダへコピーします。
複数のモデルは `<モデル名>/<バージョン>/` に分け、以前の結果を上書きしません。

コンペ横断で使う事前学習モデルや保存しておきたいモデルは、リポジトリ直下の
`models/` を利用できます。コピー方法と設定の例は
[モデルの管理手順](../../../docs/models.md) を参照してください。

新しいコンペのこのフォルダは、コンペ全体とともに Git 除外になります。
テンプレートにはモデルの実物や個人の記録を入れないでください。
